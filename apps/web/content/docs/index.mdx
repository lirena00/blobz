Blobz has two delivery paths backed by the same deterministic renderer:

| Use case | Choose | What you ship |
| --- | --- | --- |
| A React 19 application | [`@blobz/react`](/docs/react) | Local components, no network request, full generated and custom-face control |
| A website that needs a copy-paste image URL | [Hosted API](/docs/api) | A stable public endpoint protected by an approved-origin allowlist and account quota |
| A framework integration or server renderer | [`@blobz/avatar-core`](/docs/architecture#shared-renderer) | Framework-free SVG generation used internally by both products |

## Start here

- [Install the React package](/docs/react/installation) for components rendered inside your bundle.
- [Use the hosted API](/docs/api/quickstart) when you want an `<img>` URL instead.
- [Read the architecture](/docs/architecture) to understand determinism, data flow, and where each layer belongs.

Both paths normalize a seed by converting it to a string, trimming whitespace, and lowercasing it. The same normalized seed, palette, frame, and choices produce the same SVG.
