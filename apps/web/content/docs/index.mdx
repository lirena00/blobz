Choose the layer that matches how much UI you want Blobz to provide:

| Use case | Start here | What you get |
| --- | --- | --- |
| Ready-to-ship avatar interfaces | [Components](/docs/components) | shadcn-compatible components copied into your application |
| Avatar rendering inside a React application | [React Package](/docs/react) | Local components with generated and custom-face control |
| A copy-paste image URL | [Hosted API](/docs/api) | A stable hosted endpoint with origin and quota controls |

## Start here

- [Browse the component library](/docs/components) for complete UI patterns installed with the shadcn CLI.
- [Install the React package](/docs/react) when you want to build your own interface.
- [Use the hosted API](/docs/api) when you want an `<img>` URL instead.

Every path uses the same deterministic renderer. The same normalized seed, palette, frame, and choices produce the same SVG.
