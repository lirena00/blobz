## Basic setup

Generated and semantic custom avatars need no global stylesheet:

```tsx
import { Avatar } from "@blobz/react";
import { CustomAvatar } from "@blobz/react/custom";
```

Both components are usable from React Server Components because they render without hooks or browser-only APIs.

## Tree-shakable entry points

Import from the documented subpath instead of a package-wide barrel.

```tsx
// Generated avatar only
import { Avatar } from "@blobz/react";

// Semantic custom avatar only
import { CustomAvatar } from "@blobz/react/custom";
```
