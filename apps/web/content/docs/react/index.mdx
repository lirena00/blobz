import { Avatar } from "@blobz/react";

`@blobz/react` renders Blobz avatars locally. It does not call the hosted API, require an account, or consume a request allowance.

```tsx
import { Avatar } from "@blobz/react";

export function ProfileAvatar() {
  return <Avatar name="Janaki" size={64} />;
}
```

## Entry points

| Import | Exports | Use it for |
| --- | --- | --- |
| `@blobz/react` | `Avatar`, `AvatarProps`, `AvatarSize`, `createAvatarDataUri` | Name-generated avatars and optional indexed overrides |
| `@blobz/react/custom` | `CustomAvatar`, `CustomAvatarProps`, `CustomAvatarValue` | Complete semantic custom definitions |

## Which component should I use?

- Use [`Avatar`](/docs/react/avatar) for the common “stable seed in, avatar out” flow.
- Add [indexed choice overrides](/docs/react/generated-customization) when most features should stay generated but a few must be pinned.
- Use [`CustomAvatar`](/docs/react/custom-avatar) for a complete, human-readable face definition.
