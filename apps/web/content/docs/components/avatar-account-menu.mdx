## Installation

<ComponentInstallation name="avatar-account-menu" />

The CLI also installs the official shadcn Dropdown Menu and the Blobz Avatar component.

## Usage

```tsx
"use client";

import { AvatarAccountMenu } from "@/components/blobz/avatar-account-menu";

<AvatarAccountMenu
  actions={[
    { id: "profile", label: "View profile", onSelect: openProfile },
    { id: "settings", label: "Settings", onSelect: openSettings },
  ]}
  avatar={{ name: user.id, src: user.image }}
  email={user.email}
  name={user.name}
  signOutAction={{ id: "sign-out", label: "Sign out", onSelect: signOut }}
/>
```

This block is a Client Component because its action callbacks cross the menu interaction boundary.

    contentClassName: {
      description: "Class name applied to the portalled menu content.",
      type: "string",
    },
    signOutAction: { type: "AvatarAccountMenuAction", description: "Optional final action separated from the main menu items. Uses the destructive variant unless the action specifies another variant." },
    triggerLabel: { type: "string", description: "Accessible label for the avatar button. Override it to match your application's account-menu wording.", default: "Open account menu for ${name}" },
  }}
/>


The `avatar` source accepts a stable `name` and optional `src`, `frame`, `palette`, and `choices`. Images automatically fall back to the generated face.
