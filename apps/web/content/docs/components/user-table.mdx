## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/user-table
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/user-table
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/user-table
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/user-table
    ```
  </Tab>
</Tabs>

The base avatar is installed automatically.

## Usage

```tsx
import { UserTable } from "@/components/blobz/user-table";

<UserTable users={[{
  id: "janaki",
  name: "Janaki Ammal",
  email: "janaki@example.com",
  role: "Owner",
  status: "active",
  lastSeen: "2m ago",
  avatar: { name: "Janaki" },
}]} />
```

Status accepts `active`, `invited`, and `suspended`. On narrow screens, the table scrolls horizontally so every column remains readable.
