## Usage

```tsx
import { BlobAvatar } from "@/components/blobz/avatar";
import {
  BlobAvatarGroup,
  BlobAvatarGroupCount,
  BlobAvatarGroupItem,
} from "@/components/blobz/avatar-group";

<BlobAvatarGroup aria-label="Project team">
  <BlobAvatarGroupItem>
    <BlobAvatar alt="" name="Janaki" />
  </BlobAvatarGroupItem>
  <BlobAvatarGroupItem>
    <BlobAvatar alt="" name="Vikram" />
  </BlobAvatarGroupItem>
  <BlobAvatarGroupCount count={3} />
</BlobAvatarGroup>
```

Give the group a useful accessible label. Individual avatars can remain decorative when the surrounding interface provides the member names.
