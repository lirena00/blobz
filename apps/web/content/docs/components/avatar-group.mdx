## Usage

```tsx
import { Avatar, AvatarFallback, AvatarGroup, AvatarGroupCount } from "@/components/ui/avatar";

<AvatarGroup aria-label="Project team">
  <Avatar><AvatarFallback name="Janaki" palette={["#dff4ff", "#38bdf8"]} /></Avatar>
  <Avatar><AvatarFallback name="Vikram" palette={["#fff0e2", "#fa9769"]} /></Avatar>
  <Avatar><AvatarFallback name="Kalpana" palette={["#e7fbe8", "#9ce786"]} /></Avatar>
  <AvatarGroupCount count={4} />
</AvatarGroup>
```

Each avatar has its own palette and accepts an optional `AvatarImage`. Match `frame` and `size` on the count to the avatars around it. Overlap follows the document direction.

## API

`AvatarGroup` accepts div props. Give it an accessible label describing the people represented.

`AvatarGroupCount` accepts span props, `frame`, `size`, and an optional numeric `count`. It labels a positive count as “N more people”; zero, negative, and non-finite counts are hidden. Supply `children` and an `aria-label` for a custom icon or action label.
