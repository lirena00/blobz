## Installation

<ComponentInstallation name="avatar-select" />

The official shadcn Select and Blobz Avatar components are installed automatically.

## Usage

```tsx
"use client";

import { AvatarSelect } from "@/components/blobz/avatar-select";

<AvatarSelect
  defaultValue="paul"
  items={people}
  onValueChange={setSelectedPerson}
/>
```

Each item requires a stable `id`, visible `name`, and Blobz avatar props. The optional description is shown as supporting text.

### AvatarSelectOption

<TypeTable type={{
  id: { type: "string", required: true, description: "Unique item ID used by value, defaultValue, and onValueChange. Keep it stable when the person's name changes." },
  name: { type: "string", required: true, description: "Visible person name shown in both the option list and selected trigger." },
  avatar: { type: "AvatarSource", required: true, description: "Generated avatar seed with optional image URL, frame, palette, and feature choices. The selected trigger uses the same avatar as its option." },
  description: { type: "string", description: "Supporting text below the name, such as a role, team, or email address. Omitted when empty." },
}} />

The `avatar` source accepts a stable `name` and optional `src`, `frame`, `palette`, and `choices`. Images automatically fall back to the generated face.
