    ```bash
    bunx --bun shadcn@latest add lirena00/blobz/avatar-select
    ```

The official shadcn Select and Blobz Avatar components are installed automatically.

## Usage

```tsx
"use client";

import { AvatarSelect } from "@/components/blobz/avatar-select";

<AvatarSelect
  defaultValue="paul"
  items={people}
  onValueChange={setSelectedPerson}
/>
```

Each item requires a stable `id`, visible `name`, and Blobz avatar props. The optional description is shown as supporting text.
