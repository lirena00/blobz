## Usage

```tsx
import { Avatar, AvatarFallback } from "@/components/ui/avatar";
import {
  AvatarProfile,
  AvatarProfileContent,
  AvatarProfileDescription,
  AvatarProfileName,
} from "@/components/blobz/avatar-profile";

<AvatarProfile variant="outline">
  <Avatar>
    <AvatarFallback alt="" name="Lirena" />
  </Avatar>
  <AvatarProfileContent>
    <AvatarProfileName>Lirena</AvatarProfileName>
    <AvatarProfileDescription>Design & development</AvatarProfileDescription>
  </AvatarProfileContent>
</AvatarProfile>
```

Use `AvatarProfileAction` for trailing controls. Its contents remain yours to wire to your application.

## Badges

Compose a shadcn `Badge` beside the name to show a role or membership. The installation command above includes the Button and Badge components used in the previews.

For a standalone card with a biography and actions, see [Profile Card](/docs/components/profile-card).

## API

`AvatarProfile` accepts div props, `density` (`compact`, `default`, `spacious`), and `variant` (`default`, `muted`, `outline`). The defaults are `default` for both.

`AvatarProfileContent` and `AvatarProfileAction` accept div props. `AvatarProfileName` and `AvatarProfileDescription` accept paragraph props. Place the shared `Avatar` directly inside the profile row.
