## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/avatar-profile
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/avatar-profile
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/avatar-profile
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/avatar-profile
    ```
  </Tab>
</Tabs>

## Usage

```tsx
import {
  AvatarProfile,
  AvatarProfileAvatar,
  AvatarProfileContent,
  AvatarProfileDescription,
  AvatarProfileName,
} from "@/components/blobz/avatar-profile";

<AvatarProfile variant="outline">
  <AvatarProfileAvatar alt="" name={user.id} size="lg" />
  <AvatarProfileContent>
    <AvatarProfileName>{user.name}</AvatarProfileName>
    <AvatarProfileDescription>{user.email}</AvatarProfileDescription>
  </AvatarProfileContent>
</AvatarProfile>
```
