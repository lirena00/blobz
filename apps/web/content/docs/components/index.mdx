Blobz is available in shadcn's public registry. Install a component directly with its `@blobz` name. The source is copied into your project, ready to adapt.

## Installation

<ComponentInstallation name="avatar" />

The Avatar component uses shadcn's familiar `Avatar`, `AvatarImage`, and `AvatarFallback` API at your configured UI path. Add a `name` to the fallback to generate a deterministic Blobz face. Other components are installed into `components/blobz` and compose those same primitives.

Every preview includes the complete example. Open **View code** to inspect or copy it. Rounded, Circle, and Square remain separate examples, and Avatar Group has its own page.
