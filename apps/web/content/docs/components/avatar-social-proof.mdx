## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/avatar-social-proof
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/avatar-social-proof
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/avatar-social-proof
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/avatar-social-proof
    ```
  </Tab>
</Tabs>

## Usage

```tsx
import { AvatarSocialProof } from "@/components/blobz/avatar-social-proof";

<AvatarSocialProof avatars={members}>
  Joined by <strong>500+</strong> developers.
</AvatarSocialProof>
```

Use concise copy and give `groupLabel` a meaningful description when the surrounding sentence does not identify the group.
