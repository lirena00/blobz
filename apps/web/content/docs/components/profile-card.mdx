## Compact

A compact profile with a larger avatar beside the name, a short introduction, and a shared footer for supporting details and an action. The footer stacks on narrow cards.

<ComponentPreview name="profile-card"><ProfileCardExample /></ComponentPreview>

## Installation

<ComponentInstallation dependencies={["button", "badge"]} name="profile-card" />

The shared Avatar and shadcn Card components are installed automatically. This command also includes the Button and Badge components used in the previews.

## Usage

```tsx
import { ProfileCard } from "@/components/blobz/profile-card";

<ProfileCard
  avatar={{ name: "Kalpana Chawla", palette: ["#dff4ff", "#38bdf8"] }}
  name="Kalpana Chawla"
  description="Astronaut & aerospace engineer"
  bio="Exploring the skies through aerospace research and two Space Shuttle missions."
/>
```

The image is optional. Without it, or if it fails to load, the avatar uses the generated fallback.

## Featured

Use `variant="featured"` for a larger portrait and a subtle patterned header. Both variants use the same content and action slots.

<ComponentPreview name="profile-card-featured"><ProfileCardFeaturedExample /></ComponentPreview>

## Composition

Use `badge` for a role or membership badge, `metadata` for supporting details, and `actions` for your application's buttons or links. In the compact layout, the badge sits beside the name and the metadata shares the footer with the actions. Empty sections are omitted automatically.

For compact identity rows, see [Avatar Profile](/docs/components/avatar-profile).
