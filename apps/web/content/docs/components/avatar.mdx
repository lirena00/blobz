  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add lirena00/blobz/avatar
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add lirena00/blobz/avatar
    ```
  </Tab>
</Tabs>

This installs `@blobz/react`, `class-variance-authority`, and `cn` when they are not already present.

## Usage

```tsx
import { BlobAvatar } from "@/components/blobz/avatar";

<BlobAvatar
  alt="Janaki avatar"
  name="Janaki"
  size="lg"
  variant="outline"
/>
```

Use `alt=""` when a visible name beside the avatar already identifies the person.

## Circle

Use `frame="circle"` for profile photos, presence lists, and familiar account surfaces.
