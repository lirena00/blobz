## Rounded

Rounded is the default. Compose `Avatar` with an `AvatarFallback` to give every profile a deterministic face.

<ComponentPreview name="avatar"><AvatarExample /></ComponentPreview>

## Installation

<ComponentInstallation name="avatar" />

This installs the avatar at your configured shadcn UI path, along with its dependencies. If you already have a shadcn avatar, review the CLI diff and replace it with this implementation to enable generated fallbacks.

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";

<Avatar>
  <AvatarImage alt="Lirena" src="https://www.lirena.in/favicon.jpg" />
  <AvatarFallback name="Lirena" />
</Avatar>
```

`AvatarImage` displays the supplied image. `AvatarFallback` renders a Blobz face while the image loads, when it fails, or when no image is supplied. The same `name` always generates the same face. Existing text fallbacks, such as `<AvatarFallback>LR</AvatarFallback>`, work too.

Use `alt=""` on both the image and fallback when a visible name beside the avatar already identifies the person.

## Surfaces

Default displays the avatar without a border. Outline adds a contrasting ring with a small gap. Elevated places the image inside a padded card frame with a shadow. Every frame follows the same proportional crop as the generated image, including at custom sizes.

<ComponentPreview name="avatar-surfaces"><AvatarSurfacesExample /></ComponentPreview>

## Status

Add an `AvatarBadge` inside the avatar. Online, away, busy, and offline include accessible status labels. Override `aria-label` for your product's terminology.

<ComponentPreview name="avatar-status"><AvatarStatusExample /></ComponentPreview>

```tsx
<Avatar>
  <AvatarFallback name="Janaki" />
  <AvatarBadge status="online" />
</Avatar>
```

Import `AvatarBadge` from the same `@/components/ui/avatar` module.

### Indicator positions

The `position` prop accepts four logical corners and follows the document direction.

<ComponentPreview name="avatar-status-positions"><AvatarStatusPositionsExample /></ComponentPreview>

### Unread counts

Use `AvatarCount` for unread messages, on its own or alongside a status badge. Counts above 99 display as `99+`, while the accessible label announces the full count. Zero, negative, and non-finite counts are hidden.

<ComponentPreview name="avatar-unread"><AvatarUnreadExample /></ComponentPreview>

## API

### Avatar

Accepts Base UI Avatar Root props, including `ref`, `render`, and `className`, plus:

<TypeTable type={{
  frame: { type: '"rounded" | "circle" | "square"', default: '"rounded"', description: "Crop shape shared by the image and generated fallback. Rounded corners scale with the avatar size." },
  size: { type: '"sm" | "default" | "lg" | "xl"', default: '"default"', description: "Avatar dimensions: sm is 32px, default is 40px, lg is 48px, and xl is 64px. Use className for a custom size." },
  variant: { type: '"default" | "outline" | "elevated"', default: '"default"', description: "Surface treatment: default shows the avatar alone, outline adds a separated ring, and elevated adds a padded card frame and shadow." },
}} />

### AvatarImage

Accepts Base UI Avatar Image props, including `src`, `alt`, `keepMounted`, `loading`, and `onLoadingStatusChange`. Image loading and error recovery are handled by Base UI, including when `src` changes.

### AvatarFallback

Accepts Base UI Avatar Fallback props, including `delay`, `ref`, `render`, and `children`, plus:

<TypeTable type={{
  name: { description: "String or number used to generate a face. Omit when providing text or custom children.", type: "string | number" },
  alt: { description: "Generated image description. Pass an empty string when decorative.", type: "string" },
  palette: { description: "Background and body colors.", type: "readonly [string, string]" },
  choices: { description: "Optional feature selections from @blobz/react.", type: "AvatarChoiceOverrides" },
}} />

### AvatarBadge and AvatarCount

`AvatarBadge` accepts span props, optional `status` (`online`, `away`, `busy`, `offline`), and `position` (`top-start`, `top-end`, `bottom-start`, `bottom-end`). The default position is `bottom-end`. Omit `status` to provide your own badge contents.

`AvatarCount` accepts span props and a required numeric `count`. It sits at the top end of the avatar; use `aria-label` to customize the announcement.
