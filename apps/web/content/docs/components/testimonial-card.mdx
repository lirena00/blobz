## Editorial

A square portrait, thin rules, and a clear typographic hierarchy. The layout stacks on narrow screens and sits side by side when space allows.

<ComponentPreview name="testimonial-card"><TestimonialCardExample /></ComponentPreview>

The quotes and customer details on this page are illustrative sample content.

## Installation

<ComponentInstallation name="testimonial-card" />

The shared Avatar component is installed automatically.

## Usage

```tsx
import { TestimonialCard } from "@/components/blobz/testimonial-card";

<TestimonialCard
  avatar={{ name: "Avery" }}
  name="Example customer"
  quote="“Thoughtful defaults make the small details feel effortless.”"
  attribution="Design team · Example company"
/>
```

Omit `avatar.src` to use a generated face. A failed image automatically falls back to the same generated avatar.

## Compact

Use `variant="compact"` for a standalone card or a grid. Quotes wrap naturally without a fixed height.

<ComponentPreview name="testimonial-card-compact"><TestimonialCardCompactExample /></ComponentPreview>
