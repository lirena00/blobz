## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/avatar-badge
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/avatar-badge
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/avatar-badge
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/avatar-badge
    ```
  </Tab>
</Tabs>

The Blobz Avatar and official shadcn Badge components are installed automatically.

## Usage

```tsx
import { AvatarBadge } from "@/components/blobz/avatar-badge";

<AvatarBadge
  avatar={{ name: user.id, size: "lg" }}
  badge="Pro"
  description="Founder & CEO"
  name="Gagandeep Kang"
/>
```

The avatar is decorative because the person's name is displayed beside it.
