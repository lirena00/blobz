## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/presence-avatar
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/presence-avatar
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/presence-avatar
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/presence-avatar
    ```
  </Tab>
</Tabs>

The base avatar is installed automatically.

## Usage

```tsx
import { PresenceAvatar } from "@/components/blobz/presence-avatar";

<PresenceAvatar
  avatar={{ alt: "Janaki Ammal avatar", name: "Janaki", frame: "circle" }}
  status="online"
  unreadCount={3}
/>
```

The `status` prop accepts `online`, `away`, `offline`, and `thinking`. Unread counts above 99 display as `99+`. Presence and unread counts include accessible labels.
