## Usage

```tsx
import { AvatarTeamList } from "@/components/blobz/avatar-team-list";

<AvatarTeamList
  members={[
    {
      id: "janaki",
      name: "Janaki Ammal",
      description: "janaki@example.com",
      role: "Owner",
      status: "online",
      avatar: { name: "Janaki" },
    },
  ]}
/>
```

The list uses semantic `ul` and `li` elements. Avatars are decorative because every row includes the member's visible name.

The `avatar` source accepts a stable `name` and optional `src`, `frame`, `palette`, and `choices`. Images automatically fall back to the generated face.
