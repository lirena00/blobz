## Usage

```tsx
import { BlobAvatarStatus } from "@/components/blobz/avatar-status";

<BlobAvatarStatus
  alt="Ada Lovelace avatar"
  name="Ada Lovelace"
  status="online"
/>
```

Online uses green, away uses amber, busy uses destructive red, and offline uses a neutral gray. The indicator also uses `role="status"` and an accessible label, so status is not communicated by color alone. Supply `statusLabel` when the product uses different terminology.

## Indicator positions

Position the indicator at any logical corner. Logical `start` and `end` values automatically follow the document direction.
