## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/group-chat
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/group-chat
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/group-chat
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/group-chat
    ```
  </Tab>
</Tabs>

The avatar and avatar group components are installed automatically.

## Usage

```tsx
import { GroupChat } from "@/components/blobz/group-chat";

<GroupChat
  channel="release"
  participants={[{ id: "janaki", name: "Janaki Ammal", avatar: { name: "Janaki" } }]}
  messages={[{ id: "1", author: { id: "janaki", name: "Janaki Ammal", avatar: { name: "Janaki" } }, time: "9:41", text: "The new avatars are live." }]}
/>
```

Pass a `typing` person to show the live typing row. Message text is rendered as plain text, with line breaks preserved.
