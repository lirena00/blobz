## Installation

Register the [Blobz registry](/docs/components#register-the-blobz-registry) once in your project, then install:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab>
    ```bash
    npx shadcn@latest add @blobz/avatar-chip
    ```
  </Tab>
  <Tab>
    ```bash
    pnpm dlx shadcn@latest add @blobz/avatar-chip
    ```
  </Tab>
  <Tab>
    ```bash
    yarn dlx shadcn@latest add @blobz/avatar-chip
    ```
  </Tab>
  <Tab>
    ```bash
    bunx --bun shadcn@latest add @blobz/avatar-chip
    ```
  </Tab>
</Tabs>

## Usage

```tsx
import {
  AvatarChip,
  AvatarChipAvatar,
  AvatarChipLabel,
  AvatarChipRemove,
} from "@/components/blobz/avatar-chip";

<AvatarChip>
  <AvatarChipAvatar alt="" name={user.id} />
  <AvatarChipLabel>{user.name}</AvatarChipLabel>
  <AvatarChipRemove aria-label={`Remove ${user.name}`} />
</AvatarChip>
```

Always give the remove action a label that identifies what will be removed.
