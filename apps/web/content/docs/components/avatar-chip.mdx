## Usage

```tsx
import { Avatar, AvatarFallback } from "@/components/ui/avatar";
import {
  AvatarChip,
  AvatarChipLabel,
  AvatarChipRemove,
} from "@/components/blobz/avatar-chip";

<AvatarChip>
  <Avatar size="sm"><AvatarFallback alt="" name={user.id} /></Avatar>
  <AvatarChipLabel>{user.name}</AvatarChipLabel>
  <AvatarChipRemove aria-label={`Remove ${user.name}`} />
</AvatarChip>
```

Always give the remove action a label that identifies what will be removed.

## Frames

The chip follows its nested avatar automatically: a circular avatar gives it a pill shape, a rounded avatar gives it rounded corners, and a square avatar gives it square corners. Set `frame` on the `Avatar`; no additional chip prop is needed. Use `size="sm"` to keep the avatar inset and chip corners aligned. The preview above demonstrates all three, each with its own palette.
